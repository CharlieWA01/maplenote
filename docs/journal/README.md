# Journal

One file per work session or topic, named `YYYY-MM-DD-<topic>.md`.
Claude writes them as part of each task.
See `docs/DOCS-STANDARD.md`.

## Template

```markdown
# YYYY-MM-DD: <topic>

## Goal
What this session set out to do.

## What was done
The steps, in order, with the reasoning behind any choice. Link the PRs.

## Problems and fixes
What went wrong, what it turned out to be, and how it was fixed.

## How it was verified
Tests run and what they showed; what Charlie checked on real hardware.

## Impact
What changed for the user (and any cost, complexity or risk added).
```
